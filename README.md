# CVGO
 
أداة/موقع بسيط وسريع لإنشاء سير ذاتية (CV) احترافية بسهولة، مع إمكانية تخصيص التصميم وتصدير السيرة الذاتية بصيغة PDF.
 
## ✨ المميزات
 
- إنشاء سيرة ذاتية خطوة بخطوة عبر نموذج بسيط
- قوالب متعددة قابلة للتخصيص
- معاينة مباشرة (Live Preview) أثناء التعديل
- تصدير السيرة الذاتية بصيغة PDF
- واجهة سهلة الاستخدام تدعم اللغة العربية والإنجليزية

## 🛠️ التقنيات المستخدمة
 
- Frontend: (مثال: React / Vue / HTML-CSS-JS)
- Backend: (مثال: Node.js / Django / Laravel) — إن وجد
- التخزين: (مثال: LocalStorage / قاعدة بيانات)
- التصدير: (مثال: مكتبة توليد PDF).
 
## 📦 المتطلبات
 
- Node.js (نسخة 18 أو أحدث) — إن كان المشروع يعتمد عليه
- npm أو yarn
## 🚀 التثبيت والتشغيل
 
```bash
# استنساخ المشروع
git clone https://github.com/username/CVGO.git
 
# الدخول إلى مجلد المشروع
cd CVGO
 
# تثبيت الحزم المطلوبة
npm install
 
# تشغيل المشروع محليًا
npm run dev
```
 
بعد التشغيل، افتح المتصفح على العنوان:
```
http://localhost:3000
```
 
## 📖 طريقة الاستخدام
 
1. افتح التطبيق.
2. أدخل بياناتك الشخصية والمهنية (الاسم، الخبرات، المهارات، التعليم...).
4. عاين النتيجة مباشرة.
5. اضغط على زر "تصدير" للحصول على السيرة الذاتية بصيغة PDF.
